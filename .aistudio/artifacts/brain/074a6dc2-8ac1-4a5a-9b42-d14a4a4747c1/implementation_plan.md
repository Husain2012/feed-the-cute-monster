# لعبة أكل الكائنات اللطيفة (Feed the Cute Monster)

خطة تصميم وتنفيذ لعبة أطفال تفاعلية ومبهجة تعمل مباشرة داخل المتصفح بمعدل 60 إطاراً في الثانية، مع توفير زر فوري لتحميل أو نسخ كود اللعبة الكامل داخل ملف HTML واحد مستقل تماماً وجاهز للتشغيل دون الحاجة لأي خادم أو مكتبات خارجية.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تثبيت الاختيارات التالية بناءً على إجاباتك في المرحلة الأولى:
> - **طريقة التسليم والتشغيل**: تشغيل اللعبة التفاعلية مباشرة هنا في المتصفح مع أزرار مخصصة لتحميل ملف `.html` مستقل وعرض/نسخ الكود الكامل من السطر الأول إلى الأخير.
> - **الطابع اللوني والشخصية**: وحش لطيف بلون **أخضر نعناعي** مع سماء زرقاء صافية وعشب أخضر مشرق، مع **استبعاد تام لأي درجات بنفسجية أو وردية** في الواجهة والرسومات.
> - **نظام اللعب والتقدم**: **3 قلوب**، تسارع تدريجي لطيف مع ارتفاع النقاط، ومؤثرات صوتية مبهجة مولّدة برمجياً عبر Web Audio API مع زر لكتم الصوت.

---

### 1. Overview & Core Concept

- **ماذا تقدم اللعبة**: يتحكم الطفل بوحش صغير لطيف في أسفل المرعى الأخضر، حيث يطلب الوحش بصرياً في بالون تفكير واضح نوعاً محدداً من الطعام أو النجوم. تتساقط عناصر متنوعة من السماء، وعند التقاط العنصر المطلوب يحصل الطفل على نقطة مع تطاير نجوم مبهجة ومؤثر صوتي، بينما يؤدي التقاط عنصر خاطئ إلى فقدان قلب واحد وظهور تعبير وجه حزين واهتزاز لطيف.
- **الفئة المستهدفة**: الأطفال والآباء/المعلمون الباحثون عن لعبة بسيطة وآمنة وسهلة الفهم بصرياً باللغة العربية (مع دعم اللمس، الماوس، ولوحة المفاتيح).
- **القيمة الأساسية**: تجربة لعب فورية وسلسة بلا تعقيد، بالإضافة إلى ملف HTML واحد نظيف ومعلّق بالكامل يمكن حفظه ومشاركته وتشغيله على أي جهاز دون إنترنت.

---

### 2. User Experience & Visual Design

- **تدفق اللعب (Game Shell Flow)**:
  1. **شاشة البداية (Title Screen)**: مشهد حي للسماء والغيوم المتحركة والعشب والوحش النعناعي وهو يرمش ويتمايل بلطف، يتوسطه شعار اللعبة المرسوم بـ SVG مخصص، وزر واضح **"ابدأ اللعب"**، وسطر إرشاد وحيد لطريقة التحكم، مع خيارات خفيفة في الزاوية لـ **تحميل ملف HTML** أو **عرض الكود الكامل** أو **كتم الصوت**.
  2. **أثناء اللعب (Playing View)**: أكثر من 85% من مساحة اللعب مفتوحة تماماً دون أي تشتيت. في الأعلى شريط حالات شفاف وخفيف يعرض:
     - **بطاقة الطلب (Craving Bubble)** أو **بالون التفكير فوق رأس الوحش** (مع مؤشر بصري واضح في الأعلى وفوق الوحش لسهولة انتباه الطفل).
     - **القلوب الثلاثة (`3/3`)** باللون الأحمر المرجاني الدافئ مع أيقونات واضحة.
     - **النقاط وأعلى نتيجة (`tabular-nums`)** وزر إيقاف مؤقت / كتم الصوت.
  3. **الإيقاف المؤقت ونهاية الجولة (Pause / Game Over Modal)**: لوحة أنيقة وواضحة تعرض النتيجة النهائية وأعلى رقم قياسي ورسالة تشجيعية لطيفة، مع زر **"العب مجدداً"** لإعادة الضبط الفوري دون إعادة تحميل الصفحة، وزر **"تحميل ملف HTML"**.

- **الهوية البصرية ولوحة الألوان (خالية تماماً من البنفسجي والوردي)**:
  - **السماء والبيئة (60%)**: تدرج سماوي ناعم (`#E0F2FE` إلى `#BAE6FD`) مع سحب بيضاء ناعمة وشمس ذهبية دافئة (`#FDE047`)، وأرضية عشب أخضر مشرق (`#4ADE80` و `#22C55E`).
  - **شخصية الوحش النعناعي (30%)**: جسم نعناعي ناعم (`#34D399` مع بطن `#A7F3D0` وحدود `#059669`)، قرون/أذنان بلون كهرماني دافئ (`#FBBF24`)، وجنتان برتقاليتان لطيفان (`#FB923C`)، وعيون كبيرة تتابع اتجاه الطعام القريب، مع تعبيرات متغيرة (سعيد، متحمس عند فتح الفم، حزين/مندهش عند الخطأ).
  - **عناصر الطعام والتفاعل (10%)**: عناصر واضحة ومميزة التباين دون أي لون وردي أو بنفسجي:
    - تفاحة حمراء (`#EF4444`)
    - موزة صفراء (`#FACC15`)
    - نجمة ذهبية (`#F59E0B`)
    - جزرة / برتقالة (`#F97316`)
    - كمثرى خضراء فاتحة (`#84CC16`)
    - بسكويت عسل ذهبي (`#D97706`)

- **التغذية الراجعة والحركة (Game Feel)**:
  - حركة مرنة للوحش مع تأثير تمدد وانضغاط (Squash & Stretch) عند الحركة والتقاط الطعام.
  - تطاير جزيئات نجوم وكونفيتي بألوان مبهجة (ذهبي، سماوي، أخضر نعناعي، برتقالي، أحمر تفاحي) عند الأكل الصحيح، مع نص عائم (`+1`).
  - اهتزاز خفيف للمشهد (Decaying Camera Shake) عند الخطأ أو خسارة قلب لتأكيد الحدث دون إخافة الطفل.
  - أصوات لطيفة عبر Web Audio API (نغمة صاعدة مبهجة للأكل الصحيح، نغمة هابطة لطيفة للخطأ، ونغمة احتفالية عند تحقيق رقم قياسي).

### 3. Key Product Decisions & Trade-Offs

- **القرار الأول: محرك Canvas 2D معزول + مولّد ملف HTML واحد مطابق**
  - *النهج المختار*: تشغيل اللعبة في التطبيق على عنصر `<canvas>` عالي الدقة (HiDPI) بمعدل 60fps منفصل عن إعادة تصيير React، مع وجود وحدة توليد نصي تنتج **ملف HTML واحد متكامل** يحتوي على نفس المحرك والتصميم والرسومات والتعليقات البرمجية الواضحة بالعربية والإنجليزية دون أي اعتماد على مكتبات خارجية.
  - *السبب*: يضمن تجربة فائقة السلاسة داخل المتصفح، ويمنح المستخدم ملفاً واحداً نظيفاً 100% يعمل بمجرد النقر المزدوج عليه في أي متصفح.
  - *البدائل المستبعدة*: استخدام React DOM لتساقط العناصر (أقل سلاسة على الأجهزة الضعيفة ويصعب تصديره كملف HTML واحد خفيف).

- **القرار الثاني: آلية إبقاء اللعب عادلاً وممتعاً للأطفال**
  - *النهج المختار*: ضمان ظهور العنصر المطلوب بنسبة لا تقل عن ~40% من العناصر المتساقطة، مع تدرج لطيف في السرعة ومعدل التساقط كل 5 نقاط، وتغيير الطلب كل بضع نقاط صحيحة مع وميض تنبيهي لطيف في بالون التفكير.
  - *السبب*: يمنع الإحباط عند الأطفال بسبب غياب الطعام المطلوب لفترات طويلة، ويحافظ على إثارة اللعبة مع التقدم.

- **القرار الثالث: حفظ أعلى نتيجة محلياً (`localStorage`)**
  - *النهج المختار*: تخزين أعلى نتيجة محلياً في المتصفح فقط دون الحاجة لقواعد بيانات أو تسجيل دخول.
  - *السبب*: يبقي اللعبة سريعة، خاصة بالأطفال، ومتوافقة كلياً مع العمل دون اتصال في ملف HTML الواحد.

### 4. Technical Architecture & Data Strategy

```
┌─────────────────────────────────────────────────────────────┐
│                   غلاف اللعبة (Game Shell)                  │
│  [TITLE_MENU] ──▶ [PLAYING] ──▶ [PAUSED] / [GAME_OVER]      │
└─────────┬───────────────────────────────────────────┬───────┘
          │                                           │
          ▼                                           ▼
┌───────────────────────────┐         ┌───────────────────────┐
│   محرك اللعبة (Canvas)    │         │  مصدر ملف HTML الواحد  │
│  - حلقة 60fps + دلتا مقيدة │         │  - كود HTML/CSS/JS     │
│  - الوحش النعناعي + بالون  │         │    كامل مع تعليقات    │
│  - الأطعمة + الجزيئات      │         │  - معاينة الكود ونسخه  │
│  - إدخال ماوس/لمس/أسهم     │         │  - تحميل مباشر (.html) │
└─────────┬─────────────────┘         └───────────────────────┘
          │
          ▼
┌───────────────────────────┐
│  محرك الصوت (Web Audio)   │
│  - نغمات مبهجة بدون ملفات  │
│  - زر كتم الصوت (Mute)    │
└───────────────────────────┘
```

- **نموذج الحالة (State Model)**:
  - حالة الواجهة (`TITLE_MENU` | `PLAYING` | `PAUSED` | `GAME_OVER`) ونافذة عرض/نسخ الكود المستقل.
  - حالة المحاكاة الداخلية داخل حلقة Canvas: إحداثيات الوحش وسرعته، تعبير الوجه ومؤقت الانفعال، العنصر المطلوب حالياً، مصفوفة العناصر المتساقطة، ومصفوفة الجزيئات والنصوص العائمة، ومؤشر الاهتزاز، والنتيجة الحالية وأعلى نتيجة (`localStorage`).
- **تعيين التفاعلات**:
  - **التحريك**: مؤشر الماوس / السحب باللمس يتحرك بسلاسة نحو موضع الإصبع أو المؤشر، بالإضافة إلى الأسهم (`ArrowLeft`/`ArrowRight`) ومفاتيح `A`/`D` بسرعة استجابة فورية مع إيقاف الحقول العالقة عند فقدان تركيز النافذة (`blur`).
  - **أزرار الملف المستقل**: زر **"تحميل ملف HTML"** ينشئ ملف `feed-the-cute-monster.html` عبر `Blob` للتنزيل الفوري، وزر **"عرض ونسخ الكود"** يفتح عارضاً منسقاً يحتوي على الكود الكامل من السطر الأول إلى الأخير مع زر نسخ فوري.
